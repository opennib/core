# Contributing to @opennib/core

Thanks for your interest in opennib — free, open-source, fully local
dictation.

**Where development happens:** opennib is currently developed in a private
monorepo (core + the Electron desktop app + the Expo mobile app) while the
apps are prepared for release. This repository mirrors `@opennib/core`
releases. That means:

- **Issues and discussion are very welcome here** — bug reports against the
  published package, API feedback, portability findings.
- **Pull requests are hard for us to merge right now** — changes land in the
  private monorepo first and flow out with the next release. For anything
  larger than a typo, please open an issue first so the work isn't wasted.
- The full monorepo (desktop + mobile apps included) goes public as the
  project approaches v1.0, at which point normal PR flow opens up.

## Working with this package

Requirements: Node.js ≥ 22.17, npm.

```sh
npm install
npx tsc -p tsconfig.json --noEmit   # typecheck
npm run build                       # compile to dist/
npm test                            # full suite, under the Bare runtime (brittle)
```

Tests run under [Bare](https://github.com/holepunchto/bare) on purpose —
this package's production home is a Bare worker on every platform (per the
[Tether stack](https://github.com/tetherto/tips/blob/main/posts/28-05-26-the-tether-stack.md)),
and a bug caught under Bare on a laptop is a mobile bug caught early.

Ground rules for code in this package:

1. **Runtime portability** — no Node-only builtins (`fs`, `path`,
   `child_process`, …), no browser globals. See `docs/runtime-matrix.md`.
2. **The RPC contract is append-only** — `spec/` is generated by
   `npm run build:hrpc`; grow it, never renumber or repurpose.
3. **Typed errors** — extend `OpennibError`; no silent catches.
4. TypeScript strict, no `any`; named exports only.
